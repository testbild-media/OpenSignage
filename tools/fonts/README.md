# Font bundle

Every OpenSignage server and player ships the same set of fonts offline.
Nothing is ever loaded from a CDN. The bundle in `fonts/` is generated by
`tools/fonts/build_fonts.py` from the families listed in
`tools/fonts/families.json`; do not edit files in `fonts/` by hand.

```
fonts/
  manifest.json            what the server/editor/player read (see below)
  LICENSES.md              table for THIRD_PARTY_LICENSES
  <id>/<File>.woff2        subset + converted font (family has no Reserved Font Name)
  <id>/<File>.ttf          byte-identical upstream font (family declares a Reserved Font Name)
  <id>/OFL.txt             or LICENSE.txt for Apache 2.0 families
```

## Re-running

Requirements: Python 3.9+, `git`, and `pip install fonttools brotli`.

```
python tools/fonts/build_fonts.py                  # latest upstream main
python tools/fonts/build_fonts.py --commit <sha>   # rebuild an exact upstream state
python tools/fonts/build_fonts.py --verify         # check fonts/ against manifest.json
```

What the build does:

1. Makes a sparse, shallow, blob-less clone of `https://github.com/google/fonts`
   in a temporary directory outside the repository (no GitHub REST API, so no
   rate limits) and checks out only the directories listed in `families.json`.
2. Verifies the license of every family (see below) and whether it declares a
   Reserved Font Name.
3. Families without a Reserved Font Name: subsets every font to WOFF2 with
   fontTools. Families with one: copies the upstream files unchanged.
4. Measures script coverage, enforces the size budget (`budgetBytes` in
   `families.json`, 60 MB).
5. Writes `fonts/` atomically (built in `fonts.build-tmp`, then swapped in).

The upstream commit is recorded in every family entry of `manifest.json`
(`upstreamCommit`). To reproduce a bundle exactly, pass that commit with
`--commit`. The output is deterministic: the same upstream commit, the same
`families.json` and the same fontTools/brotli versions give byte-identical files
(checked by building twice from different clones). The committed bundle was built
with fontTools 4.66.1 and brotli 1.2.0 from upstream commit
`bd8f81ddb5c74d5c8897b36ad88b440266245103`. Other library versions may produce
different (but equivalent) WOFF2 bytes; rebuild and commit the whole `fonts/`
folder then.

Useful flags: `--source-dir <google/fonts checkout>` (skip the clone, e.g. offline),
`--only id1,id2 --out <dir>` (partial build for experiments), `--jobs N`,
`--allow-exclusions`.

Exit codes: `0` ok, `1` fatal (a required family failed, coverage or budget
violated, git/network error), `3` build finished but one or more non-required
families were excluded (see the `EXCLUDED` banners in the output; remove them
from `families.json` to get a clean build).

## How licenses are verified

Only SIL OFL 1.1 and Apache 2.0 are accepted. For each family the build checks:

* the upstream directory matches the declared license (`ofl/...` for `OFL-1.1`,
  `apache/...` for `Apache-2.0`);
* the license file exists and contains the expected text: `OFL.txt` must contain
  "SIL OPEN FONT LICENSE Version 1.1", `LICENSE.txt` must contain "Apache License"
  and "Version 2.0" (case and whitespace insensitive);
* the upstream `METADATA.pb` says `license: "OFL"` / `"APACHE2"`.

A family that fails any check is excluded loudly and not written to `fonts/`
(exit code 3); if it is marked `"required": true` the whole build aborts instead.
The license file is copied next to the fonts (line endings normalised to LF).
The `copyright` field is the first `Copyright ...` line of the license file; for
Apache 2.0 files, which carry no copyright line, it comes from the font's name
table (ID 0). The version in `LICENSES.md` comes from name ID 5.

## Reserved Font Names (why some families are not subset)

The OFL lets anyone use and redistribute the fonts, but a font author may declare
one or more Reserved Font Names (RFN) in the copyright notice, e.g.
`Copyright 2010 The Raleway Project Authors (...), with Reserved Font Name "Raleway".`
The rule, from SIL OFL 1.1:

* Definitions: a *Modified Version* is any derivative made by adding to, deleting
  from or substituting any component of the Original Version, "by changing formats
  or by porting the Font Software to a new environment".
* **Condition 3**: no Modified Version may use a Reserved Font Name unless the
  copyright holder gave explicit written permission.

The OFL-FAQ (https://openfontlicense.org/ofl-faq/) spells out what this means for
web fonts: Q 2.2 and 2.2.1 (a WOFF/WOFF2 conversion is not a modification only if the
original font data stays unchanged except for the compression), Q 2.6 (subsetting,
i.e. removing glyphs or layout code, is a modification), Q 2.7 (a modified webfont may
only keep an RFN under the functional-equivalence conditions described there).
Our subsetting also removes glyphs and hinting, so it cannot keep the original name.

Therefore the build applies this rule automatically:

| Family declares an RFN? | What is shipped | `modified` |
| --- | --- | --- |
| No | subset WOFF2 | `true` |
| Yes | the upstream `.ttf`/`.otf`, **byte-identical**, under its original file name | `false` |

A family declares an RFN if the copyright header of its `OFL.txt` (everything before
"This Font Software is licensed under") or the copyright/license notice in the font's
own name table (IDs 0 and 13) contains "Reserved Font Name". The name-table check
matters: Source Serif 4 declares it only there. For unmodified families the build
compares every file with its upstream git blob id and aborts if they differ (for
example because of line-ending conversion in the checkout). The only change is the
file name: `[`, `]` and `,` become `-` (`Lora[wght].ttf` -> `Lora-wght.ttf`), which is
not a modification of the font software. No hinting is removed, no table is touched.

Montserrat declares no RFN (neither its `OFL.txt` nor its name table), so it is
subset like the other non-RFN families. If upstream ever adds one, the next build
switches it to unmodified automatically. `--verify` fails if a family that declares
an RFN contains a modified file.

Consequence: the RFN families are larger and still carry hinting. The bundle is about
33 MB in total, of which about 26 MB are the unmodified RFN families. The 60 MB budget
leaves room; if it is exceeded the build first drops the optional static weights
(`extraStaticStyles`) of the RFN families, then those of the others, and keeps
Regular/Italic/Bold/BoldItalic and all variable fonts.

For Apache 2.0 fonts (Permanent Marker) modified files must carry a notice of the
change (section 4(b)); `LICENSES.md` contains it.

## Subsetting (families without an RFN)

Kept code points (only glyphs that exist in the font): U+0000-00FF, U+0100-024F,
U+0259, U+1E00-1EFF, U+2000-206F, U+20A0-20CF, U+2100-214F, U+2190-2193, U+2212,
U+2215, U+FEFF, U+FFFD, Greek U+0370-03FF, Cyrillic U+0400-04FF.
All layout features are kept (`--layout-features='*'`), variation tables are kept,
hinting is dropped, the full name table is kept.

Variable fonts are preferred (`Family[wght].ttf`, `Family-Italic[wght].ttf`,
`[wdth,wght]`, `[opsz,wght]` ...). Families without one use static files: Regular,
Italic, Bold, BoldItalic plus the optional weights listed in `extraStaticStyles`
(Light, Medium, SemiBold, Black and their italics, where upstream has them).

## manifest.json

```json
{ "version": 1, "fallback": "Noto Sans",
  "families": [
    { "id": "montserrat", "family": "Montserrat", "category": "sans",
      "license": "OFL-1.1", "licenseFile": "montserrat/OFL.txt",
      "source": "https://github.com/google/fonts/tree/<commit>/ofl/montserrat",
      "upstreamCommit": "<sha>", "copyright": "Copyright ...",
      "scripts": ["latin", "latin-ext", "cyrillic"],
      "files": [
        { "file": "montserrat/Montserrat-wght.woff2", "format": "woff2", "modified": true,
          "style": "normal", "weight": [100, 900], "sha256": "...", "size": 146892 } ] },
    { "id": "lora", "family": "Lora", "category": "serif", "...": "...",
      "files": [
        { "file": "lora/Lora-wght.ttf", "format": "truetype", "modified": false,
          "style": "normal", "weight": [400, 700], "sha256": "...", "size": 123456 } ] } ] }
```

* `format`: `woff2`, `truetype` (`.ttf`) or `opentype` (`.otf`), the same value as the
  `format()` hint of the `@font-face` `src` (`woff2`, `truetype`, `opentype`).
* `modified`: `true` for subset WOFF2 files, `false` for byte-identical upstream files.
* `category`: `sans`, `serif`, `display`, `condensed`, `script` or `mono`. Families
  are sorted in that order, then by name.
* `weight`: `[min, max]` of the `wght` axis for variable files, `[w, w]` (OS/2
  `usWeightClass`) for static files. Use it for the `font-weight` descriptor of the
  `@font-face` rule.
* `width` (optional, only for files with a `wdth` axis): `[min, max]` percent, for
  the `font-stretch` descriptor. Files without a `wdth` axis omit the field.
* `scripts`: scripts for which every file of the family has all test characters.
  `latin` = A-Z a-z; `latin-ext` = the Central/Eastern European, Baltic, Turkish and
  Romanian letters (ŁłŐőŰűČčŠšŽžĘęĄąĆćŃńŚśŹźŻżĂăȘșȚțĐđĢģĶķĻļŅņŌōŪūĒēĪīĀāĖėĮįŲųĞğİıŞşŸŒœß);
  `greek` = Α-Ω α-ω; `cyrillic` = А-Я а-я (this includes the Bulgarian letters
  Ъ ъ Щ щ). A script is only listed if all of its characters are present, so a
  font missing one letter is not listed for that script. If a family's italic lacks a
  script that its upright has (e.g. Source Code Pro), the script is not listed.
  Coverage is measured on the shipped file (for unmodified fonts that is the full
  upstream cmap).
* `fallback` is the family name of the font that must cover everything
  (latin, latin-ext, greek, cyrillic). The build fails if it does not.
* File names never contain `[`, `]` or `,`.

## Adding a family

Only fonts under SIL OFL 1.1 or Apache 2.0 can be added. Fonts that come with an
operating system cannot: for example **Bahnschrift** (Microsoft, part of Windows) may not
be redistributed, copied to servers or converted to web fonts (Microsoft's font
redistribution FAQ, https://learn.microsoft.com/en-us/typography/fonts/font-faq). Its free
counterpart in the bundle is the Barlow family in three widths: Barlow, Barlow Semi
Condensed and Barlow Condensed.

1. Find the directory in `https://github.com/google/fonts` (for example
   `ofl/ubuntusans` or `apache/...`).
2. Add an entry to `tools/fonts/families.json`:

   ```json
   { "id": "ubuntu-sans", "family": "Ubuntu Sans", "category": "sans",
     "path": "ofl/ubuntusans", "license": "OFL-1.1" }
   ```

   `id` becomes the folder name (kebab-case), `license` is `OFL-1.1` or `Apache-2.0`.
   Optional keys: `"required": true` (abort the build if it fails),
   `"mustCover": ["latin", "cyrillic"]` (abort if the shipped file lacks a script),
   `"extraStaticStyles": []` (override the optional static weights).
3. Run `python tools/fonts/build_fonts.py`, then `--verify`, and commit `fonts/`
   together with `tools/fonts/families.json`. Whether the family is subset or shipped
   unmodified is decided by the Reserved Font Name rule above; nothing to configure.

If the license check fails the family is excluded; do not work around it.
